# Versions, "Start here" and Section Underline (0.1.1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship 0.1.1 of the gallery. It adds:
- a "Start here" nav group with three pages: Getting started, Versions and Release notes
- a version picker in the header, over frozen copies of the site per release line
- release notes driven by `CHANGELOG.md`
- an animated underline on section titles

**Architecture:**
- Pure release-line logic lives in one plain-ESM module, `apps/gallery/src/content/versionLines.mjs`. The gallery and `scripts/` both import it.
- At deploy, `scripts/build-versioned-site.mjs`:
  - builds the current site at the root
  - builds each older line from its newest tag, at `/v<line>/`
  - writes `versions.json`
  - injects `version-banner.js` into the archived copies
- The gallery reads `versions.json` through a `useVersions()` hook, which the picker, the banner and the Versions page all use.

**Tech Stack:**
- React 19, Vite 7 (`?raw` imports), Vitest, Playwright
- Node `node:test` for scripts
- GitHub Actions
- No new runtime dependencies

**Spec:** `docs/superpowers/specs/2026-10-04-versions-design.md`. It's binding: read it in full first. Every task names the spec section that holds its exact values.

## Review Focus

1. **A tag set with a pre-release.** For `v0.1.0, v0.1.1, v1.0.0-rc.1, v1.0.0`, grouping must ignore the rc and still give the lines `1` and `0.1` (newest 0.1.1). Task 2 tests this.
2. **Picker on a page that doesn't exist in the target line.** Going to `<path>#/release-notes` on a line older than that page must land on that copy's NotFound page, not a blank screen. Task 5 tests the URL mapping, and 0.1.0's copy already has a NotFound page.
3. **`versions.json` missing, slow or malformed.** The picker must not throw. It shows only the current line, disabled, and the Versions page falls back to the current build. Tasks 5 and 6 test this.
4. **Dev mode with no `versions.json`.** `npm run dev` must still render every page, with the picker showing "dev (unreleased)". Task 5 tests this.
5. **Two quick section changes.** The underline replays on every section change, never on a link change inside the same section. Under reduced motion it shows the final width. Task 7 tests this.
