# Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `Icon` in `@bit-ds/react` 0.1.6. It's a curated set of 300 Material Symbols Sharp 700 icons plus their fills, usable as `<Icon icon={iconX} />` or as `bit-icon bit-icon-{name}` classes. The gallery gets an Icon page with an "All icons" section where every tile has its own Copy button.

**Architecture:**
- A root script generates two committed files from a curated `icons.json` and a pinned devDependency: a TS module of `IconData` consts, and a CSS file of `--_bit-icon` mask rules.
- `Icon` draws an inline `<svg>`. Base `.bit-icon` rules ship in `styles.css`, and the artwork classes ship in an opt-in `icons.css`.
- The gallery engine gains four small, general hooks: axis `none` sentinel, `importedProps`, an `html` override and `extraSection`. The Icon manifest uses all four.

**Tech Stack:** React 19, TypeScript, tsup, esbuild, Vitest + Testing Library, node:test, Playwright, pnpm 9 workspaces.

**Spec:** `docs/superpowers/specs/2026-10-08-icon-design.md`

## Global Constraints
- Branch `feat/icon-0.1.6`. Package version becomes **0.1.6**.
- Artwork source: `@material-symbols/svg-700` **exactly `0.47.6`**, a devDependency of `@bit-ds/react` only. Files: `sharp/{name}.svg` and `sharp/{name}-fill.svg`.
- Every source file must match exactly `<svg xmlns="http://www.w3.org/2000/svg" width="48" height="48" viewBox="0 -960 960 960"><path d="…"/></svg>`, with an optional trailing newline. The generator throws on anything else. All 600 listed files match, which was checked while planning.
- Curated list: 8 groups, 300 regular names, all with a `-fill`. That's **600** icons. No logos.
- Naming: `name` is the Material name with `_` → `-`, plus `-fill`. Export is `icon` + PascalCase(name) (`iconKeyboardArrowDown`, `iconFavoriteFill`). Class is `bit-icon-{name}`.
- Icon sizes: sm 16px, md 20px (default), lg 24px. Colour: none by default (currentColor), else `bit-{color}`.
- Decorative by default (`aria-hidden="true"`). With a non-empty `label`, it gets `role="img"` + `aria-label`. Always `focusable="false"`.
- `icons.css` is **never** part of `styles.css`. `onlyBuiltDependencies` stays `[]`. No runtime dependencies.
- Owner ruling: a future IconButton's block class is `bit-iconButton`. Nothing in this plan builds IconButton.
- Commit messages: conventional (`feat:`, `test:`, `docs:`, `chore:`), ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- The gallery resolves `@bit-ds/react` from its built `dist`. **Run `pnpm build` before any gallery test** after a library change.

## Spec amendments (found while planning; folded into the spec in Task 9)
1. **`ICON_GROUPS` shape:** `readonly { label: string; icons: readonly { regular: IconData; fill: IconData }[] }[]` replaces group → names. The gallery needs the data, and unused groups still tree-shake.
2. **Variants:** the Icon page shows one row of colours (`none` + 5) at the playground's size. That's the engine's existing rule for a page with no `variant` axis. Colour × size would change Spinner's page too.
3. **Tile glyph** is 24px (`size="lg"`), not 32px. `.bit-icon` owns the icon's width, and gallery.css may only set `--_gallery-*` custom properties.
4. **Home chip:** the Icon tile chip is the text glyph `★`. `GLYPHS` holds strings, not elements.
5. **Playground controls:** the icon picker and fill toggle are virtual controls named `iconName` and `filled`, so the docs-default contract test doesn't read them as the `icon` prop. Fill isn't an svg attribute either.

## Review Focus
1. **Icon inside a coloured Button.** `--_bit-color` inherits. An icon with no colour of its own inside `<Button color="primary">` must take the Button's text colour (currentColor), not purple. This is pinned by a CSS test and a render test in Task 2.
2. **`label=""`.** An empty label must stay decorative (`aria-hidden`), not become `role="img"` with an empty name. Pinned in Task 2.
3. **Search input with spaces, capitals or underscores** ("Arrow Back", "arrow_back") must still find `arrow-back`. Pinned in Task 5 (`normalizeQuery`) and Task 6.
4. **A consumer imports one icon.** Their bundle must not contain the other 599. Pinned by an esbuild bundle check in Task 3.
5. **Class form in Windows high contrast.** A `span.bit-icon` mask must stay visible (`CanvasText`). Pinned by a CSS test in Task 2. The existing `forced-colors.spec.ts` e2e covers pages.

```js
// How a Material Symbols file name becomes bit's icon name, React export and class. One place, used by the
// generator and by the package's export checks, so they cannot disagree.

/** `keyboard_arrow_down` → `keyboard-arrow-down`; a `-fill` suffix is kept. */
export const iconName = (material) => material.replace(/_/g, '-');

/** `keyboard_arrow_down` → `iconKeyboardArrowDown`; `favorite-fill` → `iconFavoriteFill`. */
export const iconExportName = (material) =>
  `icon${iconName(material)
    .split('-')
    .map((word) => word.charAt(0).toUpperCase() + word.slice(1))
    .join('')}`;

/** `arrow_back` → `bit-icon-arrow-back`. */
export const iconClassName = (material) => `bit-icon-${iconName(material)}`;
```

`scripts/build-icons.mjs`:
```js
// Builds bit's icons from packages/core/src/icons/icons.json and the pinned @material-symbols/svg-700
// (a devDependency of @bit-ds/react). Writes two committed files:
//   packages/react/src/icons/icons.generated.ts   one IconData const per icon, plus ICON_GROUPS
//   packages/core/src/icons/icons.generated.css   one --_bit-icon mask rule per icon (shipped as icons.css)
// Run `npm run icons` after editing icons.json. scripts/build-icons.test.mjs fails when they drift.
import { readFileSync, writeFileSync } from 'node:fs';
import { createRequire } from 'node:module';
import { dirname, resolve } from 'node:path';
import { fileURLToPath } from 'node:url';
import { iconClassName, iconExportName, iconName } from './icon-names.mjs';

const root = resolve(dirname(fileURLToPath(import.meta.url)), '..');
const requireFromReact = createRequire(resolve(root, 'packages/react/package.json'));
const PACKAGE = '@material-symbols/svg-700';

export const OUTPUTS = {
  list: resolve(root, 'packages/core/src/icons/icons.json'),
  ts: resolve(root, 'packages/react/src/icons/icons.generated.ts'),
  css: resolve(root, 'packages/core/src/icons/icons.generated.css'),
};

const SOURCE = /^<svg xmlns="http:\/\/www\.w3\.org\/2000\/svg" width="48" height="48" viewBox="0 -960 960 960"><path d="([^"]+)"\/><\/svg>\n?$/;
const EXPORT = /^icon[A-Z][A-Za-z0-9]*$/;

/** The one path in a Material file; throws when the file is anything else. */
function pathOf(file, svg) {
  const match = SOURCE.exec(svg);
  if (!match) throw new Error(`build-icons: ${file} is not a single 960-grid path`);
  return match[1];
}

/** The SVG as a CSS url(): only the characters a data URI needs are escaped, so the file stays small. */
function dataUri(path) {
  const svg = `<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 -960 960 960'><path d='${path}'/></svg>`;
  return `url("data:image/svg+xml,${svg.replace(/%/g, '%25').replace(/#/g, '%23').replace(/</g, '%3C').replace(/>/g, '%3E')}")`;
}

/**
 * The two files' text. `groups` is icons.json; `readSvg(file)` returns a file from the package's sharp/ folder.
 * Pure: the same input always gives the same output.
 */
export function buildIcons({ groups, readSvg, version }) {
  const seen = new Set();
  const icons = []; // { material, exportName, name, path }, regular then fill, in list order
  const groupLines = [];
  for (const [label, names] of Object.entries(groups)) {
    const pairs = [];
    for (const regular of names) {
      if (seen.has(regular)) throw new Error(`build-icons: listed twice: ${regular}`);
      seen.add(regular);
      const pair = [regular, `${regular}-fill`].map((material) => {
        const exportName = iconExportName(material);
        if (!EXPORT.test(exportName)) throw new Error(`build-icons: ${material} does not make a valid export name`);
        const icon = { material, exportName, name: iconName(material), path: pathOf(`${material}.svg`, readSvg(`${material}.svg`)) };
        icons.push(icon);
        return icon;
      });
      pairs.push(`{ regular: ${pair[0].exportName}, fill: ${pair[1].exportName} }`);
    }
    groupLines.push(`  { label: '${label.replace(/'/g, "\\'")}', icons: [${pairs.join(', ')}] },`);
  }
  const ts = [
    `// Generated by scripts/build-icons.mjs from packages/core/src/icons/icons.json and ${PACKAGE} ${version}. Do not edit.`,
    '// Artwork: Material Symbols Sharp 700, Copyright Google LLC, Apache License 2.0.',
    "import type { IconData, IconGroup } from './types';",
    '',
    ...icons.map((i) => `export const ${i.exportName}: IconData = { name: '${i.name}', path: '${i.path}' };`),
    '',
    "/** The curated set in the gallery's order: each group's icons with their fill versions. */",
    'export const ICON_GROUPS: readonly IconGroup[] = [',
    ...groupLines,
    '];',
    '',
  ].join('\n');
  const css = [
    '/* Generated by scripts/build-icons.mjs. Do not edit. Shipped as @bit-ds/react/icons.css, never inside styles.css. */',
    `/* Artwork: Material Symbols Sharp 700 (${PACKAGE} ${version}), Apache License 2.0, Copyright Google LLC. */`,
    ...icons.map((i) => `.${iconClassName(i.material)}{--_bit-icon:${dataUri(i.path)}}`),
    '',
  ].join('\n');
  return { ts, css };
}

/** icons.json, a reader over the pinned package's sharp/ folder, and that package's version. */
export function loadInputs() {
  const groups = JSON.parse(readFileSync(OUTPUTS.list, 'utf8'));
  const pkgJson = requireFromReact.resolve(`${PACKAGE}/package.json`);
  const sharp = resolve(dirname(pkgJson), 'sharp');
  const { version } = JSON.parse(readFileSync(pkgJson, 'utf8'));
  return { groups, readSvg: (file) => readFileSync(resolve(sharp, file), 'utf8'), version };
}

if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const { ts, css } = buildIcons(loadInputs());
  writeFileSync(OUTPUTS.ts, ts);
  writeFileSync(OUTPUTS.css, css);
  console.log(`build-icons: wrote ${(ts.match(/^export const icon/gm) ?? []).length} icons`);
}
```

```tsx
export interface IconProps extends Omit<SVGAttributes<SVGSVGElement>, 'color' | 'children'> {
  /** The icon to draw: an `iconX` export, such as `iconFavorite`. Class: `bit-icon-{icon.name}`. */
  icon: IconData;
  /** Color role. Class: `bit-{color}`. Left off, the icon is drawn in the surrounding text color. */
  color?: Color;
  /** sm 16px, md 20px, lg 24px. Class: `bit-{size}`. */
  size?: Size;
  /** What the icon means, for screen readers. Without it the icon is decorative and hidden from them. */
  label?: string;
}

/** A Material Symbols icon as an inline <svg>. It needs no stylesheet beyond styles.css. */
export const Icon = forwardRef<SVGSVGElement, IconProps>(function Icon(
  { icon, color, size = 'md', label, className, ...rest },
  ref,
) {
  const a11y = label ? { role: 'img', 'aria-label': label } : { 'aria-hidden': true as const };
  return (
    <svg
      ref={ref}
      className={toClasses(
        'icon',
        [
          { name: 'color', allowed: COLORS, value: color },
          { name: 'size', allowed: SIZES, value: size },
        ],
        className ? `bit-icon-${icon.name} ${className}` : `bit-icon-${icon.name}`,
      )}
      viewBox="0 -960 960 960"
      focusable="false"
      {...a11y}
      {...rest}
    >
      <path d={icon.path} />
    </svg>
  );
});
```

```ts
import { ICON_GROUPS } from '@bit-ds/react';
import type { IconData, IconGroup, IconPair } from '@bit-ds/react';

/** The stylesheet the class form needs, besides styles.css. */
export const ICONS_CSS_IMPORT = "import '@bit-ds/react/icons.css';";

export type CopyFormat = 'react' | 'html';

/** `keyboard-arrow-down` → `iconKeyboardArrowDown`: the export the generator gave this icon (the catalog test proves they match). */
export function exportNameFor(name: string): string {
  return `icon${name
    .split('-')
    .map((word) => word.charAt(0).toUpperCase() + word.slice(1))
    .join('')}`;
}

const BY_NAME: ReadonlyMap<string, IconPair> = new Map(ICON_GROUPS.flatMap((g) => g.icons.map((pair) => [pair.regular.name, pair] as const)));

/** An icon and its fill, by the regular name. */
export function findIcon(name: string): IconPair {
  const pair = BY_NAME.get(name);
  if (!pair) throw new Error(`bit gallery: no icon named "${name}"`);
  return pair;
}

function escapeAttr(value: string): string {
  return value.replace(/&/g, '&amp;').replace(/"/g, '&quot;');
}

/** The class form of one icon, as the Icon page's HTML tab prints it. */
export function iconHtml(icon: IconData, { color, size, label }: { color?: string; size: string; label?: string }): string {
  const classes = ['bit-icon', `bit-icon-${icon.name}`, ...(color ? [`bit-${color}`] : []), `bit-${size}`].join(' ');
  const a11y = label ? `role="img" aria-label="${escapeAttr(label)}"` : 'aria-hidden="true"';
  return `<span class="${classes}" ${a11y}></span>`;
}

/** Exactly what a tile's Copy button puts on the clipboard. */
export function copyText(icon: IconData, format: CopyFormat): string {
  if (format === 'html') return `<span class="bit-icon bit-icon-${icon.name}" aria-hidden="true"></span>`;
  const name = exportNameFor(icon.name);
  return `import { Icon, ${name} } from '@bit-ds/react';\n\n<Icon icon={${name}} />`;
}

/** Lower case, trimmed, with runs of spaces, underscores and hyphens as one hyphen: "Arrow Back" → "arrow-back". */
export function normalizeQuery(query: string): string {
  return query.trim().toLowerCase().replace(/[\s_-]+/g, '-');
}

/** The groups whose icon names contain the query, each keeping only its matches. Empty groups are dropped. */
export function filterGroups(groups: readonly IconGroup[], query: string): IconGroup[] {
  const q = normalizeQuery(query);
  if (q === '') return [...groups];
  return groups
    .map((group) => ({ label: group.label, icons: group.icons.filter((pair) => pair.regular.name.includes(q)) }))
    .filter((group) => group.icons.length > 0);
}
```
