# Passes on the Button Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Button page gains a Passes section (Wireframe, Tokens, States, Final) between Playground and Variants, held in `?pass=`, with leader lines from token callouts to the live Button, and no new gallery paint.

**Architecture:**
- **URL.** A page-key registry (`engine/pageParams.ts`) lets `useControlState` stay the only code that rewrites the URL. It keeps and cleans `?pass=` alongside the controls. `usePassParam` only reads and pushes.
- **Data.** `manifest.anatomy` lists parts (label, selector, tokens, side, anchor) and state patches. A guard test proves every token is real and read by the component's CSS, directly or through one `--_bit-*` hop into `system/*.css`.
- **Views.** Four pass views (`passViews.tsx`) render the manifest's **default** state. One hook, `useStageMeasure` (ResizeObserver, `fonts.ready`, one animation frame), feeds two pure functions: `measureLines` for the Tokens leader lines and `measureBox` for the Wireframe dimensions. `PassesSection` wraps it all in one bit Card: controls and stage in `CardBody`, the caption in `CardFooter`.

**Tech Stack:** npm workspaces, React 19 + TypeScript, react-router-dom (hash router), vitest + jsdom + Testing Library, Playwright + axe, plain CSS (gallery layout only).

**Spec:** `docs/superpowers/specs/2026-10-24-passes-design.md` (owner-approved 2026-10-24: engineering review D1–D4, design review G1–G3).

- [ ] **Step 3: Implement `pageParams.ts`**

```ts
/**
 * Page-level query keys: state a page keeps in the URL beside its controls (the Passes section's `pass`; PR D adds
 * the theme drawer's `t.*`). useControlState is the only code that rewrites the URL, so it carries these through
 * every canonical rewrite, push and replace, cleaned by each key's parser.
 */

export const PASSES = ['wireframe', 'tokens', 'states', 'final'] as const;
export type Pass = (typeof PASSES)[number];
export const DEFAULT_PASS: Pass = 'wireframe';

/** A known pass, or the default for a missing or unknown value. */
export function parsePass(raw: string | null): Pass {
  return PASSES.find((pass) => pass === raw) ?? DEFAULT_PASS;
}

interface PageParam {
  /** The canonical value to keep, or undefined to drop the key (its default, or a value it doesn't know). */
  parse: (raw: string) => string | undefined;
}

export const PAGE_PARAMS: Readonly<Record<string, PageParam>> = {
  pass: {
    parse: (raw) => {
      const pass = parsePass(raw);
      return pass === DEFAULT_PASS ? undefined : pass;
    },
  },
};

/** `next`'s control keys, then each page key from `current` that parses, in registry order. A new object. */
export function withPageParams(next: URLSearchParams, current: URLSearchParams): URLSearchParams {
  const out = new URLSearchParams([...next].filter(([key]) => !(key in PAGE_PARAMS)));
  for (const [key, param] of Object.entries(PAGE_PARAMS)) {
    const raw = current.get(key);
    const value = raw === null ? undefined : param.parse(raw);
    if (value !== undefined) out.append(key, value);
  }
  return out;
}
```

/** The component's CSS file name: the anatomy override, else the kebab-case of the name (IconButton → icon-button.css). */
export function cssFileFor(manifest: Manifest): string {
  return manifest.anatomy?.css ?? `${manifest.name.replace(/([a-z0-9])([A-Z])/g, '$1-$2').toLowerCase()}.css`;
}

/** Every custom property a stylesheet reads with var(). */
export function varReads(css: string): Set<string> {
  return new Set([...css.matchAll(/var\(\s*(--[\w-]+)/g)].map((match) => match[1]!));
}

/** Every value a stylesheet declares for one custom property. */
export function declarations(css: string, property: string): string[] {
  const escaped = property.replace(/-/g, '\\-');
  return [...css.matchAll(new RegExp(`${escaped}\\s*:\\s*([^;]+);`, 'g'))].map((match) => match[1]!);
}

/**
 * Every anatomy token must be a theme token, and the component must read it: directly, or through a `--_bit-*`
 * property it reads whose declaration (in its own file or in system/*.css) reads the token. One hop, by design.
 */
export function anatomyErrors(
  manifest: Manifest,
  componentCss: string | null,
  systemCss: readonly string[],
  themeTokens: readonly string[],
): string[] {
  const anatomy = manifest.anatomy;
  if (!anatomy) return [];
  const file = cssFileFor(manifest);
  if (componentCss === null) return [`${manifest.slug} anatomy: packages/core/src/components/${file} does not exist`];
  const reads = varReads(componentCss);
  const privates = [...reads].filter((name) => name.startsWith('--_bit-'));
  const sheets = [componentCss, ...systemCss];
  const readThroughPrivate = (token: string) =>
    privates.some((name) => sheets.some((css) => declarations(css, name).some((value) => varReads(value).has(token))));
  return anatomy.parts.flatMap((part) =>
    part.tokens.flatMap((token) => {
      if (!themeTokens.includes(token)) return [`${manifest.slug} anatomy "${part.label}": ${token} is not a theme token`];
      if (reads.has(token) || readThroughPrivate(token)) return [];
      return [`${manifest.slug} anatomy "${part.label}": ${token} is not read by ${file}, directly or through a --_bit-* property it reads`];
    }),
  );
}

```ts
import { useEffect, useEffectEvent, useState } from 'react';
import type { RefObject } from 'react';

/**
 * Measures the stage after layout, and again when it resizes or fonts finish loading: everything that moves a
 * leader line or a dimension. Callbacks are batched into one animation frame. Each pass view mounts fresh, so a new
 * pass always measures, with no dependency list to forget. Without ResizeObserver (jsdom), it returns `empty`.
 */
export function useStageMeasure<T>(stage: RefObject<HTMLElement | null>, measure: (stage: HTMLElement) => T, empty: T): T {
  const [value, setValue] = useState<T>(empty);
  const run = useEffectEvent(() => {
    if (stage.current) setValue(measure(stage.current));
  });

  useEffect(() => {
    const element = stage.current;
    if (!element || typeof ResizeObserver !== 'function') return;
    let live = true;
    let frame = 0;
    const schedule = () => {
      cancelAnimationFrame(frame);
      frame = requestAnimationFrame(() => {
        if (live) run();
      });
    };
    const observer = new ResizeObserver(schedule);
    observer.observe(element);
    schedule();
    if ('fonts' in document) {
      void document.fonts.ready.then(() => {
        if (live) schedule();
      });
    }
    return () => {
      live = false;
      cancelAnimationFrame(frame);
      observer.disconnect();
    };
  }, [stage]);

  return value;
}
```

  to: Point;

  x: number;
  y: number;

  height: number;
  paddingLeft: number;

/** A point on a box. */
export function anchorPoint(box: DOMRect, anchor: AnchorPoint): Point {
  const cx = box.left + box.width / 2;
  const cy = box.top + box.height / 2;
  switch (anchor) {
    case 'center':
      return { x: cx, y: cy };
    case 'top':
      return { x: cx, y: box.top };
    case 'bottom':
      return { x: cx, y: box.bottom };
    case 'left':
      return { x: box.left, y: cy };
    case 'right':
      return { x: box.right, y: cy };
    case 'bottom-right':
      return { x: box.right, y: box.bottom };
  }
}

const relative = (point: Point, origin: DOMRect): Point => ({ x: point.x - origin.left, y: point.y - origin.top });

/** One line per part: from its callout's edge facing the instance to its anchor on the part, relative to the stage. */
export function measureLines(stage: HTMLElement, parts: readonly AnatomyPart[]): Line[] {
  const origin = stage.getBoundingClientRect();
  const instance = stage.querySelector('[data-instance]');
  if (!instance) return [];
  const callouts = [...stage.querySelectorAll<HTMLElement>('[data-part]')];
  return parts.flatMap((part) => {
    const target = instance.querySelector(part.selector);
    const callout = callouts.find((el) => el.dataset.part === part.label);
    if (!target || !callout) return [];
    const edge = callout.getBoundingClientRect();
    const from = { x: part.side === 'left' ? edge.right : edge.left, y: edge.top + edge.height / 2 };
    const to = anchorPoint(target.getBoundingClientRect(), part.anchor ?? (part.side === 'left' ? 'left' : 'right'));
    return [{ part: part.label, from: relative(from, origin), to: relative(to, origin) }];
  });
}

/** The instance's box relative to the stage, and its left padding, for the Wireframe dimensions. */
export function measureBox(stage: HTMLElement): BoxMeasure | null {
  const target = stage.querySelector<HTMLElement>('[data-instance] > *');
  if (!target) return null;
  const origin = stage.getBoundingClientRect();
  const box = target.getBoundingClientRect();
  return {
    x: box.left - origin.left,
    y: box.top - origin.top,
    width: box.width,
    height: box.height,
    paddingLeft: parseFloat(getComputedStyle(target).paddingLeft) || 0,
  };
}

import { useCallback, useEffect, useRef, useState } from 'react';
import type { CSSProperties } from 'react';
import { useSearchParams } from 'react-router-dom';
import { Button, Card, CardBody, CardFooter, Code, SegmentedControl, Stack, Text } from '@bit-ds/react';
import type { Manifest } from '../../../manifests/types';
import { DEFAULT_PASS, parsePass, PASSES } from '../../../engine/pageParams';
import type { Pass } from '../../../engine/pageParams';
import { useStageMeasure } from './useStageMeasure';
import { FinalPass, measureBox, renderedClasses, StatesPass, TokensPass, WireframePass } from './passViews';

const NAMES: Readonly<Record<Pass, string>> = { wireframe: 'Wireframe', tokens: 'Tokens', states: 'States', final: 'Final' };

/** One sentence per pass, shared by every component. */
const SHOWS: Readonly<Record<Pass, string>> = {
  wireframe: 'The box only: its height and padding, measured from the page. No color, so you can see the bones.',
  tokens: 'Each part points to the tokens it reads. Change a token and this is everything that moves.',
  states: 'The states its props set, side by side. The last one is live: point at it, press it, or Tab to it.',
  final: 'The finished component and the JSX that makes it.',
};

/** Below this stage width the callouts stack under the instance and the lines go away. */
const STACK_BELOW = 600;

/** The pass in the URL. Reads and pushes only: useControlState is the one code that cleans the URL. */
export function usePassParam(): { pass: Pass; setPass: (next: Pass) => void } {
  const [search, setSearch] = useSearchParams();
  const pass = parsePass(search.get('pass'));
  const setPass = useCallback(
    (next: Pass) => {
      if (next === pass) return;
      const params = new URLSearchParams([...search].filter(([key]) => key !== 'pass'));
      if (next !== DEFAULT_PASS) params.append('pass', next);
      setSearch(params);
    },
    [pass, search, setSearch],
  );
  return { pass, setPass };
}

const nextOf = (pass: Pass): Pass => PASSES[(PASSES.indexOf(pass) + 1) % PASSES.length]!;

/** What the pass reads, built from data and the rendered instance, never typed per component. */
function readsFor(manifest: Manifest, pass: Pass, stage: HTMLElement | null): string {
  const anatomy = manifest.anatomy!;
  switch (pass) {
    case 'wireframe': {
      const box = stage ? measureBox(stage) : null;
      return box ? `height ${Math.round(box.height)}px, padding-left ${Math.round(box.paddingLeft)}px` : '';
    }
    case 'tokens':
      return anatomy.parts.map((part) => `${part.label}: ${part.tokens.join(', ')}`).join(' · ');
    case 'states':
      return anatomy.states.map(({ label, state }) => `${label}: ${Object.keys(state).join(', ') || 'no props'}`).join(' · ');
    case 'final':
      return stage ? renderedClasses(stage) : '';
  }
}

/** Four squares, filled for each pass seen. Inline svg, so the paint isn't gallery CSS. Decorative. */
function Pips({ seen }: { seen: ReadonlySet<Pass> }) {
  return (
    <svg className="gallery-passes__pips" width={58} height={10} aria-hidden="true">
      {PASSES.map((pass, i) => (
        <rect
          key={pass}
          x={i * 16 + 1}
          y={1}
          width={8}
          height={8}
          stroke="currentColor"
          strokeWidth={1.5}
          fill={seen.has(pass) ? 'currentColor' : 'none'}
        />
      ))}
    </svg>
  );
}

export function PassesSection({ manifest }: { manifest: Manifest }) {
  const { pass, setPass } = usePassParam();
  const [seen, setSeen] = useState<ReadonlySet<Pass>>(() => new Set([pass]));
  const [spoken, setSpoken] = useState('');
  const [reads, setReads] = useState('');
  const stageRef = useRef<HTMLDivElement>(null);
  const stacked = useStageMeasure(stageRef, (el) => el.getBoundingClientRect().width < STACK_BELOW, false);

  useEffect(() => {
    setSeen((current) => (current.has(pass) ? current : new Set([...current, pass])));
  }, [pass]);

  // Reads depends on the rendered instance (Wireframe's sizes, Final's classes), so it fills in after commit.
  useEffect(() => {
    if (manifest.anatomy) setReads(readsFor(manifest, pass, stageRef.current));
  }, [manifest, pass]);

  if (!manifest.anatomy) return null;
  const parts = manifest.anatomy.parts;
  const rows = Math.max(parts.filter((p) => p.side === 'left').length, parts.filter((p) => p.side === 'right').length);
  const next = nextOf(pass);

  const goNext = () => {
    setPass(next);
    setSpoken(`${NAMES[next]}, pass ${PASSES.indexOf(next) + 1} of ${PASSES.length}`);
  };

  return (
    <Card className="gallery-passes">
      <CardBody>
        <div className="gallery-passes__controls">
          <SegmentedControl
            legend="Pass"
            legendHidden
            name="pass"
            options={PASSES.map((value) => ({ value, label: NAMES[value] }))}
            value={pass}
            onValueChange={(value) => setPass(parsePass(value))}
          />
          <Button variant="outline" onClick={goNext}>{`Next: ${NAMES[next]}`}</Button>
          <Pips seen={seen} />
          <Text size={14}>{seen.size === PASSES.length ? 'All 4 seen' : `${seen.size} of 4 seen`}</Text>
          <span role="status" className="gallery-visually-hidden">
            {spoken}
          </span>
        </div>
        <div
          ref={stageRef}
          role="group"
          aria-label={`${NAMES[pass]} pass: ${manifest.name}`}
          className="gallery-passes__stage"
          style={{ '--_gallery-passes-rows': String(rows) } as CSSProperties}
        >
          {pass === 'wireframe' ? <WireframePass manifest={manifest} /> : null}
          {pass === 'tokens' ? <TokensPass key={String(stacked)} manifest={manifest} stacked={stacked} /> : null}
          {pass === 'states' ? <StatesPass manifest={manifest} /> : null}
          {pass === 'final' ? <FinalPass manifest={manifest} /> : null}
        </div>
      </CardBody>
      <CardFooter>
        <Stack gap={8}>
          <Text size={14} weight="bold">
            What this pass shows
          </Text>
          <Text size={16}>{`${SHOWS[pass]} The default ${manifest.name}. Change it in the Playground above.`}</Text>
          {pass === 'final' ? <Text size={14}>Default props aren&apos;t printed in the code.</Text> : null}
          <Text size={14} weight="bold">
            Reads
          </Text>
          {reads ? <Code>{reads}</Code> : null}
        </Stack>
      </CardFooter>
    </Card>
  );
}
